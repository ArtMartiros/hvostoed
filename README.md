# Хвостоед

Головоломка про змей, которые едят друг друга за хвост. Тапаешь змею — она стреляет
взглядом вперёд: увидела чужой хвост, проглотила целиком и **переняла направление
съеденной**. Увидела тело или голову — авария. Увидела край — улетела с поля, и её
длина пропала навсегда.

**Играть: https://artmartiros.github.io/hvostoed/**

## Что внутри

| Пак | Что это |
|---|---|
| **Пустота** | 19 уровней с целью по длине, от обучающих до длинных с бюджетом |
| **Рекорд** | 3 больших поля 12×16 без цели: играешь, пока есть кого есть, счёт — самая длинная змея за партию |
| **Кампания** | 25 старых уровней с валунами и колючими змеями |

Лампочка в шапке делает один ход настоящей лучшей линии — можно натыкать её подряд
и увидеть правильный порядок. Партия с подсказками в рекорд не идёт.

## Железное правило

Ни один уровень не едет без прогона солвера — и это не обещание, а ворота в CI:

```
node solver.js hvostoed.jsx    # геометрия и решаемость всех уровней
node records.mjs hvostoed.jsx  # поля рекорда: достижимость потолка, разрыв с тупой игрой
node hints.mjs hvostoed.jsx    # подсказка доводит до цели за минимум ходов и до потолка
node plancheck.mjs 4           # игра проходит задуманный план генератора, ход в ход
node ending.mjs hvostoed.jsx   # партия кончается ровно тогда, когда рост невозможен
```

Проверки берут данные из самого файла игры, а `hints.mjs`, `plancheck.mjs` и
`ending.mjs` вырезают и исполняют её собственный код — тестируется то, что реально
поедет, а не копия.

Карта проекта на одну страницу — [CLAUDE.md](CLAUDE.md): правила, файлы, проверки и
договорённости. Как устроены уровни, чем меряется сложность и какие ошибки уже
совершены при генерации — в [hvostoed-brief.md](hvostoed-brief.md).

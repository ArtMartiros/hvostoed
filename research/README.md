# research/ — замеры к market-analysis.md

Скрипты вырезают логику игры из hvostoed.jsx по якорю `const SIDES = { n:` (как
ending.mjs) и гоняют её на уровнях паков — числа в отчёте «замер» отсюда.
Запуск из этой папки, голый Node 22; выхлоп JSON — в `out/` (в git не идёт).

| скрипт | что меряет | факты |
|---|---|---|
| `measure.mjs` | полный граф состояний 74 плоских уровней: безопасность ходов, ловушки, точные вероятности звёзд для политик «случайный ход / сначала обед / жадный» | Ф12–Ф14 |
| `naive.mjs` | поток MVP: «инстинкт Arrows» (есть вылет — выпускай) против «едока» и случайного тапера | Ф15 |
| `casual.mjs` | 63 уровня без механик и генератор по полосам «Азбуки»: 1★/3★ у политик, доля побед одной змеёй | Ф14, Ф16, Ф18 |
| `finale.mjs` | чем кончается победа: одна змея, смотрящая в край | Ф16 |
| `escape.mjs` | правила Arrows на досках «Хвостоеда», гибрид «цель — пустое поле» | Ф20 |
| `crit_mid.mjs` | вероятности 1★/2★ по пакам | Ф13 |
| `stream.mjs` | фильтр «едок берёт 1★ наверняка» по размерам досок | Ф18 |
| `uniq.mjs` | число разных досок полосы с точностью до симметрий | Ф18 |
| `ceilcheck.mjs` | потолок генератора против точного `ceilingOf` из solver.js | Ф18 |
| `daily_probe.mjs` | доска дня по дате: время сборки, точный потолок | Ф18 |

`stream.mjs` и `uniq.mjs` импортируют genintro.mjs, а он при импорте пишет
`intro-pack.out` в текущую папку — запускать отсюда, файл в git не идёт.
